# ADR-0011: 支援 PWA (Progressive Web App)

## 狀態
已接受

## 背景
MeetHalf 主要在手機上使用，需要提供類似原生應用的體驗，包括：
- 安裝到主畫面
- 離線支援
- 推播通知
- 快速啟動

## 決策
實現完整的 PWA 支援。

## 實現細節
- **Web App Manifest**:
  - 定義應用名稱、圖示、主題顏色
  - 支援「加入主畫面」功能

- **Service Worker**:
  - 實現基本離線支援
  - 快取靜態資源
  - 支援推播通知

- **PWA 功能**:
  - 安裝提示
  - 邀請碼功能（PWA 安裝後使用）
  - 離線頁面

## 理由
- **用戶體驗**:
  - 類似原生應用的體驗
  - 快速啟動（無需打開瀏覽器）
  - 離線基本功能

- **推播通知**:
  - PWA 模式下支援背景推播
  - 提高用戶參與度

- **降低開發成本**:
  - 無需開發原生 iOS/Android 應用
  - 單一程式碼庫支援多平台
  - 快速迭代和部署

- **現代化**:
  - 符合現代 Web 標準
  - 良好的瀏覽器支援

## 限制
- **iOS 支援**:
  - iOS Safari 對 PWA 支援有限
  - 某些功能可能無法使用

- **功能限制**:
  - 無法訪問所有原生 API
  - 性能可能不如原生應用

## 後果
- 需要維護 Service Worker
- 需要處理離線狀態
- 需要測試多個瀏覽器和平台
- 但 PWA 提供了最佳的跨平台解決方案
